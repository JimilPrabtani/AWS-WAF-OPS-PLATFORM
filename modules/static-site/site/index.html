WAF Ops Platform

Origin content served from a private S3 bucket, reachable only through CloudFront with Origin Access Control. Every request to this page is evaluated by an AWS WAF Web ACL first.

This page exists as a target for the attack and false-positive suites. It is deliberately static and contains no application logic.

  • Direct origin access returns 403 — verified in CI.
  • Blocked requests return a JSON body, not a bare status code.
  • Request logs land in CloudWatch Logs under aws-waf-logs-*.
